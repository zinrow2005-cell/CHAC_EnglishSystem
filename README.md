## 下一個必要步驟
需有逐字可靠的錄音內容（英文單字、例句、中文與解說），才能完成八階段 SOP 的第 2、3、4、5 階段：核對單字、逐字切段、獨立繪製不混圖的蠟筆圖卡、接入遊戲。

請開啟 `mn-review.html` 聽寫，完成後下載 JSON 回傳。也可直接在聊天中提供逐字稿。
