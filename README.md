# CHAC英文系統 V61 — 字母拼拼樂

沿用 V60 的 A～G 38 個單字、蠟筆圖卡、老師錄音、PWA 與遊戲選字母功能。

## 新增第五種遊戲

「字母拼拼樂」：點圖片聽英文，依單字長度顯示方格，下方列出打亂的英文單字字母；點擊字母逐格填入。字母可重複使用的情況（例如 apple 的 p）會以兩個獨立按鈕提供。拼錯可以點已填方格、退回一格或重新排列；拼對顯示「答對了！」並開放下一題。每局至多 5 題、完成時一次結算星星。

- 使用 `assets/game-pictures/` 的無文字圖片，避免直接看到答案。
- 沿用 V60 的單字母／多字母／全部／隨機範圍設定。
- 使用既有共用英文朗讀及答對語音回饋（依瀏覽器支援）。
- 支援滑鼠與手機/iPad 點擊操作，無需實體鍵盤。
- PWA service worker 快取包含新增 `spell-game.js`。

## 上傳 GitHub

先上傳 `CHAC_V61_01_MAIN_PWA.zip` 解壓後內容，再上傳 `CHAC_V61_02_MEDIA.zip` 解壓後內容至同一儲存庫根目錄；GitHub 網頁無法直接解壓 ZIP。各包檔案數小於 100。若已部署 V60，且影音資源沒有更動，可僅上傳第一包更新的檔案。

## 測試限制

已檢查 JavaScript 語法、圖片資源路徑、ZIP 內容及每包檔案數；尚未在真實 iPad/手機進行逐題點擊及語音的實機測試。
