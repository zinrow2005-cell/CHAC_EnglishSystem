# CHAC V63.9｜M–N 字母入口顯示修正版

## 問題與修正
V63.8 因為移除未經錄音核對的 M–N 單字卡，字母選單又是由已收錄單字產生，所以連 M、N 字母入口都消失。V63.9 改成從課程 `tracks[].letters` 取得 A–N 字母選單，讓 M、N 即使尚未建立正式單字卡，也可以點選。

- A–L：64張已收錄的舊單字卡保持原樣；五種遊戲維持只使用已收錄單字。
- M–N：可以點選字母、查看字母發音提示、播放 `audio/MN.m4a` 完整老師原音、進入 `mn-review.html` 記錄核對備註。
- M–N：單字圖片、例句、分段圖音配對**仍不會出現在正式學習內容**，因尚未與錄音核對，避免沿用錯誤配對。
- 進度頁將 M、N 顯示成「錄音待核對」而非「0/0」。
- 專注學習模式中選取 M、N 時會導向錄音核對頁，不再出現空白字卡視窗。
- 不清除 LocalStorage 學習紀錄；PWA 快取版號更新為 V63.9。

## GitHub 使用方式
如果已完整安裝 V63.8，將此修正包解壓後覆蓋 GitHub 儲存庫相同路徑。確認 `audio/MN.m4a` 也存在。清除網站資料可能清掉本機學習進度，請勿為了解除快取而先刪除網站資料。

## 待完成
M–N 仍需要可靠的老師原音轉寫、字詞比對及重新製圖，現在**只是恢復字母入口與完整原音播放**。
