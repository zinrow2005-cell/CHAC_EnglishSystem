# CHAC 英文教材系統 V62.6｜純蠟筆圖片版

以 V62.5 為基礎，保留 A–J 54 字、教師原音、例句、學習紀錄和五種遊戲。

## 修改重點
- 一般單字卡的**圖片區僅顯示蠟筆插圖**，移除左上角「Aa・1」等編號標籤。
- 原有的 `assets/card-art/` 共 54 張圖已是無英文／中文文字的插圖，因此**不重新產圖**，保留其品質與目前的放大比例。
- 英文、中文、例句繼續顯示在圖片下方的內容區，不會誤刪。
- 專注學習的大圖使用相同無文字插圖；五種遊戲和教師錄音不變。
- 版本升為 V62.6，更新前端資源版本與 PWA 快取版本。
- 新預覽圖僅顯示插圖，不再額外疊加英文／中文標題。

## GitHub 更新方法
此增量包適用 **V62.5 已安裝完整素材** 的儲存庫。解壓更新包後，將內部檔案按相同路徑覆蓋到 GitHub 儲存庫根目錄（不是直接上傳 ZIP）。

若仍看到舊標籤，等 GitHub Pages 部署完成，關閉分頁再開啟，必要時清除該網站的快取／離線資料。
