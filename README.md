# CHAC V63.6.2｜A–N 75 張正式教材

新增 PB1 M–N 老師課堂錄音的11個單字、11張獨立蠟筆字卡與11張遊戲圖、10份切割老師原音（Mommy + Mop 共用），並新增字母 M/N 發音教學。保留 A–L 舊版全部64張字卡、錄音與學習進度資料結構。

GitHub 更新：先解壓 ZIP 並將內部檔案依原相對路徑覆蓋儲存庫。若曾部署 RC1，請刪除遠端 `mn-review.html` 與 `mn-review-manifest.json`。系統不使用 Node.js，GitHub Pages 可直接部署靜態檔。
