# CHAC V63.0｜蠟筆字卡視覺校正與系統驗收

# CHAC V62.9｜字卡與畫面檢查修正版

從 V62.6 更新，保留 A–J 共 54 個單字、教師錄音、五種遊戲與瀏覽器學習紀錄。

## 修正
- 所有 54 張 `assets/card-art/` 圖片重整成 900×640、四周留足安全邊距，僅保留蠟筆圖案，不把中英文放入圖片。
- 切換字母時立即清掉舊字卡，顯示當前字母載入狀態；新圖片預先載入後才顯示卡片；使用切換序號防止快速點擊亂序。
- 不使用 smooth scroll 掠過舊畫面；初始進站已設定首頁模式，減少舊介面先出現的情況。
- 專注模式切換圖片時先隱藏上一張，完成載入後顯示，避免舊圖殘影。
- 圖片統一 `object-fit:contain`，不裁切；尺寸和留白兼容桌機、手機及平板。
- 更新 CSS/JS 快取參數與 PWA service worker 版本至 629。

## GitHub 使用方式
已完整安裝 V62.6 時：解壓 `CHAC_V62.7_GitHub_修正更新包.zip`，把所有檔案覆蓋到 GitHub 儲存庫的同一相對路徑，確認 Pages 部署完成後重新開啟頁面。

未安裝 V62.6 的使用者請改用四包完整安裝檔，先解壓合併於網站根目錄；切勿直接把壓縮檔作為網站內容上傳。

## 驗收範圍
已做圖片像素安全邊距、圖片數量與檔案完整性檢查，瀏覽器模擬驗收結果另外列於檢測報告。實際舊版 Safari、GitHub Pages 遠端快取仍需於使用端確認。


## V62.9 實測調整
- 十個字母、54 張插圖、五種遊戲與44份老師片段完成 Chromium 測試。
- 修復 320px 窄螢幕在捲動字卡時，頂部導覽列覆蓋圖片的問題。
- 將桌機／手機頂部導覽底色改為不透明，降低捲動時文字穿透的觀感。
- 未更動教材、單字、老師音檔或學習進度儲存結構。


## V63.0 修正
- 54張卡片用圖及54張遊戲用圖的紙張背景色統一處理，去除原有拼接方形底色。
- A–J 單字卡的主要插圖、專注學習與遊戲圖片統一版本參數為 `v=630`。
- Service Worker shell 和媒體快取版本同步更新至 v630。
- 保留原有教師錄音、單字、例句、學習進度儲存格式。
