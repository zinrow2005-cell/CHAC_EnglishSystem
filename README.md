# CHAC V63.8｜M–N 原音待核對安全版

此版本是針對 V63.5–V63.7 **未先確認 M–N 錄音內容便自作字卡** 的問題所做的安全處理。

- 暫時不在正式學習頁與遊戲題庫顯示尚未核實的 10 張 M–N 圖卡、例句或圖音配對。
- 保留既有 A–L 的 64 張字卡，以及既有學習紀錄 Local Storage 鍵值（不清除使用者資料）。
- 保留完整原音 `audio/MN.m4a`，可在老師錄音選單播放，或開啟 `mn-review.html`。
- 核對頁不再出現推測的 M–N 字詞和秒數，僅播放原音，提供按時間跳轉與文字備註。
- M–N 原來的素材仍可能留在 GitHub 既有檔案或快取中，但系統不會使用。完整備份中亦保留，不代表內容已經核實。
- **這不是完成了 M–N 逐字轉錄的正式教材。** 必須先獲得可靠的原音逐字稿，才可重新對齊單字、例句、錄音與圖片。
