# CHAC 英文系統 V62.3 — H–J 老師錄音切點調整與播放修正

**版本基礎：V62.2，完整 A–J 54 字、108 張蠟筆圖，保留老師原始音檔與五種遊戲。**

## 這次變更
- 對 `PB1 H-J.m4a` 使用 31 dB 相對門檻、最短 0.23 秒的停頓檢測，在原本 12 處段落交界尋找安靜區中點，重編碼 H–J 共 13 份教學片段。
- 依然是 16 張字卡：House/Hat、Insect/Ink、Jam/Jelly 各共用一段，其餘 10 字獨立。
- 修正專注學習老師原音播放的停止、片段結束狀態、調整後秒數預聽與開頭／結尾校正；不會將「播放已結束」誤當成正在播放。
- `clipmap.js`、`teacher-segments.js`、`v6.js`、`index.html`、`sw.js` 更新；版本快取改為 V62.3。
- 本版是**波形／停頓校正**，**未逐字人工試聽核對每句完整性**；保留清楚的「待人工確認」狀態。
- 學習進度與原本使用的 `pbClipEdits37` 使用者微調記錄不改寫。

## 套用方式
若 GitHub 已安裝 V62.2，下載 `CHAC_V62.3_GitHub_錄音校正更新包.zip`，解壓後將同路徑檔案覆蓋到 GitHub 儲存庫根目錄並重新部署即可。舊 A–J 圖片不用再傳。

要從頭安裝可使用 V62.3 三包版本，將三包內容解壓合併於同一根目錄，**不是上傳三個 ZIP 檔案**。
