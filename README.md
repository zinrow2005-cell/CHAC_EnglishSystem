# CHAC V62.9 H–J 蠟筆重繪更新包

這一包已將 H、I、J 的 16 張字母圖卡重新由原始蠟筆總圖仔細裁切並置入系統的 `assets/card-art/`。

## 已更新單字
- H：house, hat, hair, horse, hand
- I：insect, ink, ill, inch, invitation
- J：jacket, jam, jelly, jug, jar, jungle

## 說明
- 每張圖都從原始總圖獨立裁切，不使用平均切格。
- 已避免切到旁邊圖案的邊緣。
- 已保留足夠安全留白，不會把自己的圖裁掉。
- 這次只更新 H–J，A–G 可之後再依同方式處理。

## 安裝方式
若你目前已有系統版本：
1. 解壓本 ZIP。
2. 將 `assets/card-art/` 內同名檔案覆蓋到 GitHub 儲存庫相同路徑。
3. 重新部署後重新整理頁面。
